# 把露營搬回家 · 2026.09.12 庭院烤肉趴

原訂露營因營區道路中斷取消，改成在自家庭院辦的一場烤肉趴。這是完整的執行企劃。

**線上看** → 開啟 GitHub Pages 網址即可（見下方設定說明）

## 這份企劃在做什麼

核心策略只有一句：**用前置工序與擺盤，把平價食材做出精緻感** —— 不靠提高食材單價。調味料全部使用家中現有庫存，全案唯一必買的耗材是竹籤。

- **9 人**（葷食 8、素食 1）· 自家庭院 · 炭火爐＋瓦斯爐＋氣炸鍋
- **分道上菜**：4 道 course，每道熱騰騰上桌，不是把生食全倒上烤網
- 飲料與酒水不列入預算（請朋友自備）

## 五個頁籤怎麼用

| 頁籤 | 什麼時候看 |
|---|---|
| **總覽** | 統計、三爐火力調度甘特圖、四道菜、五件不能忘的事 |
| **採買** | 可勾選的採購清單（依通路分區）、花費分類分析、份量分析 |
| **備料** | 週五晚上：醃漬時間軸、醬料配方、串燒組裝圖、工序表 |
| **現場** | 週六：炭火三區配置圖、當天時間軸、每道菜的爐上參數 |
| **細節** | 完整長版六章，查細節用的底本 |

## 兩個互動功能

- **人數滑桿**（葷食／素食分開調）：肉品照葷食人數、蔬菜照總人數即時重算，木炭竹籤等固定成本不變
- **採購清單可勾選**：邊逛賣場邊勾，狀態自動存在瀏覽器

> ⚠️ 勾選狀態存在各自的裝置裡，**不會跨裝置同步**。兩個人分頭採買的話，進度要另外對。

## 技術

單一 HTML 檔，無外部相依、無需網路（下載後離線可看）。所有資料是檔案內的單一資料來源，四個視圖從同一份資料渲染，所以份量與金額不可能互相矛盾。

四張 SVG 圖表（三爐甘特、醃漬時間軸、烤網三區配置、串燒組裝）皆為手繪 SVG，色票通過對比度與色盲辨識度驗證，light／dark 雙模式。

## 上線設定（GitHub Pages）

1. Repo → **Settings** → 左側 **Pages**
2. Source 選 **Deploy from a branch**
3. Branch 選 **main**、資料夾選 **/ (root)** → Save
4. 等 1-2 分鐘，網址會是 `https://<你的帳號>.github.io/<repo 名稱>/`
